# 轻译 · 英中同声字幕

本项目采用 MIT 许可，详见 [LICENSE](LICENSE)。在线字幕使用 MyMemory，须遵守其服务条款；详见 [隐私说明](PRIVACY.md)。

一个无需构建工具的 Chrome 扩展。字幕模式优先读取 DeepLearning.AI 课程页面自带的定时字幕，再尝试网页和内嵌播放器中的 `<video>` 活动字幕轨及可见英文字幕，使用 Chrome 内置 Translator API 翻译。声音模式捕获当前标签页音频，交给 Chrome 语音识别，再用同一翻译引擎输出中文字幕。声音识别的临时结果会合并，防止连续更新让中文翻译一直无法显示。软件和 AI 语境下有术语归一规则，例如英文字幕提到 `agent` 时，将译文中的“代理人/代理”统一显示为“智能体”。

翻译引擎检查、语言包下载和单句翻译都有明确的等待上限。下载进度或错误会一直显示在浮窗，不会被字幕轮询清除；失败后点击「重试翻译」。如果浏览器尚未安装英中语言包，点击浮窗的「下载英中语言包并开始」。首次下载取决于网络，不能算作实时翻译速度。

如果 Chrome 语言包下载超时，可在扩展菜单选择「在线字幕」。这是用户主动启用的备用模式，会把当前英文字幕发送到 [MyMemory](https://mymemory.translated.net/doc/spec.php) 的翻译接口；按该服务的[官方用量说明](https://mymemory.translated.net/doc/usagelimits.php)，匿名免费额度为每天 5,000 字符。课程页面会提前翻译下一句以减少播放时的等待。在线模式需要网络，速度和可用性取决于该服务。

隐私说明见 [PRIVACY.md](PRIVACY.md)：本地字幕翻译在 Chrome 内处理；在线模式会把字幕发送给 MyMemory；声音模式可能使用 Chrome 提供的语音识别服务。请勿把含机密内容的字幕发送到在线模式。

## 安装与使用

1. 使用桌面版 Chrome 138 或更新版本。打开 `chrome://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，选中本目录。更新代码后在扩展卡片点击「重新加载」，并刷新视频页面。扩展需要访问网页及其内嵌播放器页面才能读取字幕。
2. 打开带英文视频的普通网页，点击扩展图标，选择「通过英文字幕」或「通过标签页声音」。字幕模式需先在播放器中开启英文字幕。
3. 初次使用时，点击网页右下角的「下载英中语言包并开始」。下载后翻译在设备上运行。点击浮窗 `×` 或扩展里的「停止翻译」结束。

## 实际限制

- 字幕模式只识别网页可访问的字幕轨和已适配的字幕 DOM；视频画面中烧录的文字不能读取。跨域 iframe 内的字幕也可能读取不到。
- 声音模式依赖 Chrome 对 `SpeechRecognition.start(audioTrack)` 的支持以及其语音服务可用性。部分 Chrome 配置可能拒绝音轨输入；浮窗会显示错误。语音识别可能使用在线服务。
- 无法保证零延迟。字幕模式等待站点字幕出现和本机翻译；声音模式还要等待识别结果。首次下载语言包需要联网。
- 目前只处理一个标签页；页面刷新后需要重新启动。Chrome 内部页和扩展商店页不支持注入。
